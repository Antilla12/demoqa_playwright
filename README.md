# DemoQA Playwright Automation

UI automation testing suite for [DemoQA](https://demoqa.com) using **Playwright + JavaScript**, with Page Object Model structure, accessibility checks, and Allure reporting.

## What's covered

### Elements
- Text Box
- Check Box
- Radio Button
- Web Tables
- Buttons
- Links
- Upload / Download
- Dynamic Properties

### Forms
- Practice Form (multi-field form submission)

### Alerts, Frames & Windows
- Browser Alerts

### Widgets
- Accordion
- Date Picker
- Slider
- Progress Bar
- Tabs
- Tool Tips
- Menu
- Select Menu

### Interactions
- Sortable
- Selectable
- Resizable
- Drag and Drop
